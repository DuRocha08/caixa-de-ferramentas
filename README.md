# 🧰 Caixa de Ferramentas

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

Uma caixa de utilitários interativa, rápida e colorida — com tema claro e escuro, desenvolvida em HTML, CSS e JavaScript puro.

🌐 **Acesse o projeto:** [Caixa de Ferramentas](https://durocha08.github.io/caixa-de-ferramentas/)

## ✨ Funcionalidades

- 🧾 **Divisor de conta** — calcula o valor total com gorjeta e quanto cada pessoa deve pagar;
- 🔐 **Gerador de senhas** — cria senhas de 6 a 30 caracteres com números e símbolos opcionais;
- 🌡️ **Conversor de temperatura** — converte Celsius para Fahrenheit e Kelvin;
- 🕘 **Histórico** — guarda os últimos cinco usos no navegador com `localStorage`;
- 🌓 **Tema claro e escuro** — muda a aparência da aplicação em um clique;
- 📱 **Interface responsiva** — organizada em abas para facilitar a navegação.

## 🎨 Visual

O projeto usa uma identidade visual limpa em azul, com cartões, abas, resultados destacados e um tema escuro acionado por troca de classe.

## 🛠️ Tecnologias

- **HTML5** — estrutura da aplicação;
- **CSS3** — layout, cores, responsividade e temas;
- **JavaScript** — cálculos, navegação, histórico e interação.

## 🚀 Como executar

### Pelo navegador

Acesse a versão publicada:

**https://durocha08.github.io/caixa-de-ferramentas/**

### Localmente

```bash
git clone https://github.com/DuRocha08/caixa-de-ferramentas.git
cd caixa-de-ferramentas
```

Depois, abra o arquivo `index.html` no navegador ou utilize uma extensão como **Live Server** no VS Code.

## 📁 Estrutura do projeto

```text
caixa-de-ferramentas/
├── index.html       # Estrutura da página
├── estilo.css       # Estilos e temas
├── script.js        # Funções e interações
└── README.md        # Documentação do projeto
```

## 📜 Histórico de usos

Os últimos cinco resultados são armazenados localmente no navegador. Nenhum dado é enviado para um servidor.

Para apagar o histórico, clique em **Apagar tudo** na seção correspondente.
